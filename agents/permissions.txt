# 許可コマンドprefixの単一ソース(1行1コマンド、前方一致)。
# ここを編集して make generate を実行すると、
# .codex/rules/my.rules と .claude/settings.json の permissions.allow/ask/deny が再生成される。
# 生成先を直接編集しないこと。編集後は make permissions-check で判定を検証する。
#
# セクション(Codex decision / Claude キー):
#   [allow]     確認なしで実行      (allow / allow)  ※Codex ではサンドボックス外で実行される
#   [prompt]    毎回確認            (prompt / ask)
#   [forbidden] 実行させない        (forbidden / deny)
# 複数一致したときは厳しい判定が勝つ(forbidden > prompt > allow)。
# 前方一致のため、オプションを引数の後ろに置いた形(例: git push origin main --force)は捕捉できない。
#
# 意図的に載せないもの(サンドボックス外実行を許すと実質全許可になる/取り消せない):
#   rm, curl, 汎用インタプリタ(bash -c, python -c, node -e, source), npx/uvx/dlx,
#   uv run の丸ごと許可, docker run, クラウド系CLI(aws, gcloud, terraform, kubectl)
